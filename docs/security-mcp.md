# セキュリティの群の MCP の使い分け

[README に戻る](../README.md)

セキュリティの群には、`--mcp-guide <パス>` で、MCP の使い分けを書いた TOML を渡せます。`run` と `estimate` が同じ引数を受け、ほかの群に渡すと起動の前にエラーになります。ファイルは MCP の名前ごとの表に、使う変更を書く `use_for` の一文だけを持ちます。MCP の名前は、利用者が `mcp.json` に登録した名前です。下の例の `mobile-sec` と `server-sec` は説明のための仮の名前で、そういう名前の MCP が配られているわけではありません。

```toml
[mcps.mobile-sec]
use_for = "iOS と Android のアプリのコード"

[mcps.server-sec]
use_for = "サーバ、API、サーバ上で動くプラグインのコード"
```

jigane は読む前に三つを確かめ、外れたら起動の前に止めます。

- 形：最上位は `mcps` の表だけで、各表は `use_for`（空でない文字列）だけを持つこと。知らない鍵はエラーです
- 名前：`mcp.json` の `mcpServers` にあること
- 集合：名前の集合が `--mcps` と同じであること。`--mcps` を渡さずに `--mcp-guide` だけ渡すと、集合が違うのでエラーです

確かめた中身は、セキュリティのプロンプトに「- <名前>: <use_for>」の箇条書きで入り、見積もりの入力にも数えます。`--mcp-guide` を省くと使い分けの文は渡しません。
