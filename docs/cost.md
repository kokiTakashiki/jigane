# 起動の回数と費用

[README に戻る](../README.md)

`jigane run` は、起動の前に `claude -p` の起動の回数と見積もりの額を示し、同意を求めます。標準入力が端末でないときは起動しません。方針の群は、PR と範囲のレビューで最大 5 回（図の起動 1 回と、原則ごとの起動が最大 4 回）、設計書のレビューで 1 回起動します。図の起動は常に走り、原則の起動は、その原則を問える形が図にあるときだけ走ります。PR と範囲のレビューの目安は、図の起動が 0.36 USD、原則の起動が 1 回あたり 0.02 USD で、全起動の和で 0.44 USD です。図の起動は claude-sonnet-5-5、原則の起動は claude-haiku-5-5 です。同意の画面と `jigane estimate` の額は、実際に組み立てた起動の上限の和です。すべての原則が見送りでも、図の起動は走ります。同意の画面には、すべての原則を問うとき `発見役: 図の起動 1 回 × 1 回の目安 0.36 USD + 原則の起動 4 回 × 1 回の目安 0.02 USD = 0.44 USD` と出ます。`jigane estimate` の text には `原則の起動: claude-haiku-5-5 4 回（1 回の目安 0.02 USD）` と `全起動の和の目安（超えることがある）: 0.44 USD` が出ます。実際の額は、検証役の回数と出力の量で変わります。この額は実額の予測ではありません。実装とセキュリティの群は、シャードの数（最大 4）と検証役の分を起動します。検証役の回数は見つかった指摘の数で決まり、上限を持ちません。1 回の起動の上限は「[jigane run](commands.md#jigane-run)」の節に書いています。判断の地図の区間に、アダプタの無い言語のソースのファイルがあるときは、費用の同意の y に続けて、もう一つ確かめます。Markdown、JSON、YAML、TOML のような文書とデータの形式と、拡張子の無いファイルは、アダプタの無い言語のソースのファイルに数えません。

図の形の方針は、起動の前に、プロンプトのバイト数を約 2.25 で割ったトークン数に 1 時間のキャッシュの書き込みの単価を掛け、出力の見込み（図の起動 3,000 トークン、原則の起動 12,000 トークン）を足した額を見積もります。この額が 1 本の上限以上なら、起動せず見送ります。単価は [Anthropic の価格表](https://platform.claude.com/docs/en/about-claude/pricing)（2026-11-04 に確認）に従います。Claude Code 自身のプロンプトの分は数に入らないので、この額は目安で、実額が上限を超えることがあります。既定の上限で見送りが始まる大きさは、原則の起動でプロンプトがおよそ 157,000 バイト、図の起動でおよそ 185,000 バイトです。`jigane estimate` の文と `--json` の `input_cost_usd` は、図の形では出力の見込みを含む額です。単価の表に無いモデルを `--model` で選ぶと最高の単価で見積もります。既定の上限では、原則の起動は出力の見込みだけで上限に達するので、プロンプトの大きさによらず常に見送られます。図の起動は、プロンプトがおよそ 23,600 バイトに達すると見送られます。

言語ごとのファイルを示し、それらの区間は宣言を読まずに「確認」になること、アダプタは `jigane languages` で足せることを伝えます。そのうえで「それでもレビューを実施しますか（y/N）」と問い、y か yes のときだけ起動します。設計書のレビューでは問いません。
