# jigane 0.1.12 のお知らせ

0.1.12 の変更を機能追加、仕様変更、不具合修正に分けて紹介します。個々の変更と使い方は「変えたこと」の表から確認できます。

## 機能追加

macOS と Linux では、Codex で方針、実装、セキュリティのレビューを実行できます。Codex CLI に保存した ChatGPT ログインを使います。

Codex の方針レビューでは、差分に応じて設計原則ごとにモデルを使い分けます。注意点として、「関心の分離」（P4）は、jigane 独自の模擬試験で見落としが多かった観点です。

Codex でも、端末で `jigane run <レビュー> security --mcps <名前>` を実行すると、指定した MCP サーバの資料を参照できます。

Codex の非対話実行では、1群ずつ USD 換算の見込みと指定額を照合します。

## 仕様変更

セキュリティレビューでは、`--mcps` に使いたい MCP サーバーの登録名を指定します。省略すると MCP は使いません。実行前の確認画面で選択した名前を確認できます。

Claude Code と Codex のどちらでも、`jigane show <レビュー> security` は、選択したサーバー名と、資料本文の取得を確認できたサーバー名を分けて表示します。

選んだ CLI が、指定した MCP サーバーに直接接続します。これまで `mcp.json` を使っていた方は、利用する CLI に合わせて登録を移してください。[MCP の設定と移行](../security-mcp.md)

更新後は、最初のレビューを実行する前にエージェントを一度選びます。
Claude Code を使い続ける場合は `jigane select-agent claude`、Codex を使う場合は `jigane select-agent codex` を実行してください。

Codex の費用は、実行後に報告された使用量をモデルの単価で USD に換算して表示します。費用が不明な起動を含むときは、既知の額と不明な起動数を表示します。

## 不具合修正

Claude Code または Codex CLI が MCP サーバーへの接続や資料の取得に失敗したと報告した場合、jigane の実行結果で確認できます。

0.1.12 の準備中に、指摘箇所のファイルパスを表す出力形式を OpenAI が受け付けず、レビューが始まらない問題を修正しました。

配布用パッケージで `jigane --version` が前の版を表示する問題を修正しました。0.1.12 のパッケージでは `jigane 0.1.12` と表示します。

## 想定される質問

### 更新後に最初に何をすればよいですか

レビュー資料をどのサービスに送るかを選ぶため、初回にエージェントを指定します。選択は保存され、次回からは従来どおり `jigane run <レビュー> <群>` を使えます。

`jigane select-agent --show` で選択を確認できます。切り替えるときは `jigane select-agent` をもう一度実行してください。

ソースから導入する場合は `make setup` でも選べます。未選択の環境で自動化するには、たとえば `JIGANE_AGENT=codex make setup` と指定します。

### Codex のレビューには何が必要ですか

macOS または Linux に Codex CLI を導入し、`codex login` で ChatGPT にログインしてください。ログイン状態は `codex login status` で確認できます。

通常の `jigane run` と非対話実行は、どちらもこのログインを使います。

端末には、OpenAI に送る資料と送信先が表示されます。同意すると、jigane が組み立てた差分の抜粋、図表などを送ります。Codex のセキュリティレビューでは、提示した資料を基に指摘の根拠と対策を確認します。

### どのモデルが担当し、何を見落としましたか

方針レビューでは P1 と P2 を GPT-6 Luna、P3 と P5 を GPT-6.1 Terra、P4 を GPT-6.2 Sol が担当します。

P4 は、たとえば口座を解約する関数に、通知の送信や統計の更新まで入り込んでいないかを調べる観点です。jigane 独自の模擬試験で、同じ4問を各モデルに1回ずつ出し、あらかじめ決めた指摘をすべて挙げた問題を完答としました。

| P4 を解いたモデル | 完答した問題 |
|---|---:|
| GPT-6 Luna | 0 / 4 |
| GPT-6.2 Sol | 1 / 4 |
| GPT-6.1 Terra | 0 / 4 |
| Claude Code の Haiku 5.5 | 4 / 4 |

4問のうち3問では、Codex の3モデルすべてで指摘が0件でした。関心の分離を確かめたい箇所では、Codex の指摘がなくても、変更した関数とその呼び先を人が確認してください。

P4 以外では、P1 の資料で値の定義と直接比較を区別した後、上記の担当で16問すべてに完答しました。
この回の生成は合計 0.0846 USD 相当でした。
P3 の資料で変更前後の引数を照合できるようにして同じ16問を解き直した回も、16問すべてに完答し、合計 0.0704 USD 相当でした。

### 費用はいつ分かりますか

通常の Codex 実行では、出力の長さや追加検証の回数が実行前には決まりません。`jigane estimate` で初期の起動数と資料サイズを、`jigane debug prompt` で初期のレビュー資料を確認できます。

実行後は `jigane usage <レビュー>` で使用量と USD 換算額を確認できます。換算には Codex CLI が報告したトークン数とモデルの公開単価を使います。契約に基づく請求額は OpenAI 側で確認してください。

費用が不明な起動を含む場合、JSON の合計 `cost_usd` は `null` になります。既知の額と不明な起動数は別のフィールドで確認できます。

### 非対話で1群を実行するにはどうしますか

`jigane estimate <レビュー> <群>` で、実行したい群の USD 換算見込みを確認します。
送信する資料を確認し、`jigane debug run <レビュー> <群> --yes --max-usd <額>` を実行します。指定できる額は 1 USD までです。

群の見込みが指定額以内のときに資料を送ります。実行後の換算額は指定額を超えることがあります。
