# jigane 0.1.7 のお知らせ

0.1.7 では、読めない言語のソースや文書だけの範囲を、レビューの前に案内するようにしました。`jigane run` の終了コード 3 の範囲が広がり、同意の確認に群の見込みが出ます。方針の資料では、Java、C#、Swift で読める図が増えました。

## 想定される質問

### 更新の後に、必要な操作はありますか

文法の取得のやり直しは通常は要りません。Claude Code の下限（2.1.308）と文法の版は変えていません。

レビューの保存物の形式が変わりました。0.1.6 までのレビューは、読み込むときに新しい形へ移されます。元のファイルは書き換えません。新しい形のレビューを 0.1.6 の jigane で読むと、「形の版がこの jigane の読める版より新しい」という誤りで止まります。0.1.6 のコードの版の検査を読んで確かめました。0.1.6 と行き来するときは、jigane を更新してください。

`jigane run` の終了コード 3 で分岐するスクリプトがあれば、[run の結果の節](#run-の結果はどう変わりましたか)を確かめてください。

### 言語の取得は、どう変わりましたか

`jigane languages fetch python swift` のように名前を並べると、その言語だけを取得します。何も書かなければ、すべてを取得します。知らない名前があれば、同意を尋ねる前に終了コード 2 で止まります。

文法がまだ無いだけの言語は、`languages` 以外の副コマンドを止めなくなりました。名前が標準エラーに出ます。

### レビューの前の案内は、何が増えましたか

範囲のファイルに、解析しない言語のソースがあるとき、`new`、`estimate`、`run` が標準エラーに案内を出します。文法が無い言語には `jigane languages fetch <言語>` を、アダプタの無い言語にはアダプタの追加かプラグインの有効化を案内します。`run` は、費用の同意の後に「それでもレビューを実施しますか」と尋ねます。

変更したファイルがすべて文書（.md、.rst、.txt）の範囲は、方針が本文を読まないので、`new` が警告し、`run` が注意します。文書は `jigane new design-doc <パス>` でレビューします。

### 費用の表示は、どう変わりましたか

同意の問いと、`estimate --json` の `expected` に、群の見込みが増えました。実装とセキュリティの群は、発見役の見積もりに、過去の回から引いた検証役の倍率を掛けた額です。見積もりは目安であり、実額を保証しません。

方針は、原則の起動の上限を 0.02 USD から 0.04 USD にしたので、全起動の和の目安が 0.44 USD から 0.52 USD になりました。式と単価は [docs/cost.md](../cost.md) にあります。

### run の結果は、どう変わりましたか

0.1.6 までは、シャードか検証の分割が失敗したときだけ終了コード 3 を返しました。0.1.7 では、どの群でも、起動の失敗か天井による見送りで指摘が欠けたときに返します。この回で最終的に通らなかったものだけを数えます。欠けの中身は `--json` の `failures` と `run.budget_stops` にあります。

図の起動が失敗するか見送られた方針の回は、方針の指摘を置き換えず、前の回の結果を残します。そのことは `run` の知らせと `show` に出ます。

### refresh と指摘の記録は、どう変わりましたか

範囲のレビューの `refresh` は、先端を枝の名前や HEAD で作っていれば、範囲を解き直して先端を進めます。SHA で作った範囲も、作ったときに先端だった枝が記録されていれば、その枝の今の先端へ進みます。作業ディレクトリを消した後も回を作れます。基点を失ったときは止めて、作り直しを案内します。

前の回の指摘の番号も `pick`、`hold`、`object` で受け付けます。

### 方針の資料は、何が変わりましたか

Java と C# は、判別の流れ図、ファイルの名前の組み立て、足した型と同じ項目を持つ型、足した公開の口と呼ぶ側を読みます。Swift は、保存物の書く側と読む側のうち、`UserDefaults`、Codable の JSON、Keychain を読みます。

読まない図は次のとおりです。副コマンドの引数は三言語とも読みません。保存物の書く側と読む側は、Java と C# が読みません。言語ごとの対応は `jigane languages list` で確かめられます。

クラス図は、変更した型の兄弟の型（共通の基底と、その基底を継承する別の型）を名前だけで出します。技術選定の表は、消えた技術が他のファイルで使い続けられていればその場所を、同じ変更で増えた技術があればその名前を示します。

### シーケンス図の JSON は、どう変わりましたか

図に `id` と `root_id`、矢印に `id` の項目が増えました。値は中身から決まり、同じ入力からは同じ値になります。既存の項目は変えていません。
