# jigane 0.1.8 のお知らせ

0.1.8 では、jigane が読めない記述（構文エラー、Swift の演算子関数、C# のクラス直下の文など）を、レビューの前に案内し、レビューの結果にも警告として残すようにしました。レビューの結果の保存形式の版が上がります。

## 変えたこと

| No. | 対象 | 変えたこと | 関わる質問 |
| --- | --- | --- | --- |
| 1 | `new`、`estimate`、`run` | 範囲のファイルに、jigane が読めない記述があるとき、レビューの前に標準エラーで案内します。`run` は続けるかを尋ねます。0.1.7 まで、名前を取れない宣言でレビューが止まっていた不具合（公開リポジトリの [issue 6](https://github.com/kokiTakashiki/jigane/issues/6)）を直しました。 | [読めない記述の案内は、何を知らせますか](#読めない記述の案内は何を知らせますか) |
| 2 | `jigane show` と `--json` | 読めない記述を、レビューの結果に警告として出します。 | [レビューの結果の警告は、どう変わりましたか](#レビューの結果の警告はどう変わりましたか) |
| 3 | レビューの保存形式 | 警告を保存する `gates.json` の形式の版が 2 から 3 に上がります。 | [更新の後に、必要な操作はありますか](#更新の後に必要な操作はありますか) |
| 4 | Swift の保存先の読み取り | 走査が途中で止まったファイルの、途中までの結果を残さなくなりました。 | [Swift の保存先の読み取りは、どう変わりましたか](#swift-の保存先の読み取りはどう変わりましたか) |

## 想定される質問

### 更新の後に、必要な操作はありますか

文法の取得のやり直しは要りません。Claude Code の下限（2.1.308）と文法の版は変えていません。0.1.7 との差分を読んで確かめました。

レビューの保存物の形式が変わりました。`gates.json` の形式の版が 2 から 3 に上がります。0.1.7 までのレビューは、読み込むときに新しい形へ移されます。0.1.8 で作ったり更新したりしたレビューを 0.1.7 の jigane で読むと、「形の版がこの jigane の読める版より新しい」という誤りで止まります。0.1.7 と行き来するときは、jigane を更新してください。

`jigane run` の答えを自動で渡すスクリプトがあれば、確かめてください。読めない記述を含む範囲では、`run` が「それでもレビューを実施しますか（y/N）」と尋ねます。y か yes 以外の答えでは、レビューを起動せずに止まります。

### 読めない記述の案内は、何を知らせますか

次の三つの記述を、案内の対象にします。当たったファイルは、経路と行を、規則ごとの件数とともに示します。差分のレビューでは、変更前の木にある記述に「変更前」が付きます。

- 構文エラー。アダプタのあるすべての言語が対象です。
- Swift の演算子関数。`static func +` のように、名前が識別子でない関数です。
- C# の名前を取れない宣言。クラス直下に書いた `Foo.Bar(x);` のような文です。

案内は、0.1.7 の読めない言語の案内の後に続けて出します。出す場所は同じ標準エラーで、`--json` の結果、終了コード、オプションは変わりません。`run` は、費用の同意の後に、二つの案内を合わせて一度だけ続けるかを尋ねます。設計書のレビューでは出ません。テストのファイルは対象です。

jigane は、言語仕様の上で書ける記述でも、読めない記述はサポートしません。案内に出た記述は、一部の検査で読まれず、その対象から外れます。続けた場合も、その記述についてのレビューの結果は保証しません。

案内の末尾には、当たった種類ごとに直し方を一度だけ示します。同じ種類が何件あっても、直し方は一度です。警告の説明にも、同じ文を載せます。

- 構文エラーは、その箇所を直してください。わざと壊したテスト用の入力なら、その旨を人が確かめてください。
- Swift の演算子関数は、中身を名前のある関数に移し、演算子からその関数を呼んでください。
- C# の名前を取れない宣言は、文をメソッドかコンストラクタの中に移してください。C# では、クラス直下に文を書けません。

### レビューの結果の警告は、どう変わりましたか

案内に出た読めない記述は、レビューの結果にも警告として残ります。`jigane show` の警告の列と、`--json` の `gates.warnings` に、構文エラー、Swift の演算子関数、C# の名前を取れない宣言の項目が並びます。項目には、記述のある経路と行、変更前か変更後か、該当行の本文が載ります。

警告は、変更した行に絞らず、`new` と `refresh` の時点の木から作ります。終了コードは変わらず、警告は数えません。読めない記述が無いレビューの出力は、これまでと同じです。

### Swift の保存先の読み取りは、どう変わりましたか

方針の資料のために、Swift の `UserDefaults`、Codable の JSON、Keychain の使い方をファイルごとに集めます。走査が途中で例外により止まったファイルについて、0.1.7 までは止まる前に集めた分だけを残していました。0.1.8 は、そのファイルの結果を残さず、走査が最後まで通ったファイルの結果だけを使います。ほかのファイルの結果には影響しません。
