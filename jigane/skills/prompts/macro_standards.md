## 出す指摘の基準

方針の指摘を出せる機会は、この PR のときしかありません。ただし、手戻りの大きいものだけに絞ります。

- 出す: 上の二つの問いに当たり、いま直さずにマージすると、後で直すときの手戻りが大きいもの。同じ形の手が積み重なり、直す場所が増えていく道筋も出します。
- 手戻りの大きさは、その形が契約になるかで測ります。契約とは、保存物（ファイル、表、JSON）の形、副コマンドの引数と書き出すファイルの名前、モジュールの境を越えて読まれる型、公開のシグネチャです。契約になる形は、マージの後に読む側と保存されたものが増えるほど直しにくくなります。いまの読む側が少ないこと、PR の中にしか読む側が無いことは、手戻りが小さい理由にしません。新しい機能では、読む側はマージの後に増えるからです。
- 出さない: 関数の共有の仕方、テストの抜け、確かめ方の穴、内部ロジックの誤り。これらは、実装が決まってから気がつく話であり、外形に見えても出しません。実装のレビューの受け持ちです。命名、表示の文言、局所の整理、任意の提案、デザインパターンを使えという提案も出しません。モジュールの中に閉じ、契約のどれにも現れない形も出しません。ただし、自作の仕組みを既製の道具に替える提案（M6）は、契約に現れなくても出します。
- severity は critical か warning だけを使い、nit は出しません。
  - critical: このまま進むと目的に届かず、マージした後では引き返す費用が大きいことが、図から確かめられたもの。
  - warning: いま道筋を変えないと、同じ形の手が積み重なり、後で直す費用が増えていくもの。
- $scope_rule
- 「前の回の直し方への深掘りになる」は、捨てる理由にしません。深掘りは deepens に前の回の番号を書いて出します。必読に数えません。
- 捨てる理由は、根拠の位置を示せないもの、図と矛盾するもの、利用者の異議が付いた論点、前の回で決着した形を元へ戻させるもの、既知の限界として開示済みの論点の五つだけです。discarded の各要素には、理由の一文（reason）に加えて、次の表の種類（kind）と、懸念の一文（concern）を書きます。前の回と同じ論点で、その行の根拠の位置にあった形がいまの図に残っていることを示せないものは、直ったので決着した形に当たります。reason に直ったと書きます。図と矛盾しない指摘は、確信が持てなくても出します。concern は、対象と懸念を一文で言い切る短い文で、「懸念」「恐れ」「疑い」「可能性」のどれかを含み、「〜であり」「〜く」のような接続の形で終えません。捨てた理由や断りは reason に書き、concern には入れません。

### 手戻りの大きい外形の欠陥

次の型に当たり、警告にする条件を満たすものを warning にします。claim の根の形は、根の直し方を出発点にします。

| 欠陥 | 警告にする条件 | 根の直し方 |
| --- | --- | --- |
| 閉じた値の集合を文字列や数で持つ | その値が契約に現れる | 列挙型にし、値ごとの分岐は型検査の網羅（match と assert_never）で確かめる |
| 種類ごとの固有データを共有の型の任意の項目に置く（不正な状態を表せる型） | 種類と項目の組に、意味の無い組み合わせを作れる | 種類ごとの型に分けた和にし、固有データはその種類の型だけが持つ |
| 種類を項目の有無や否定で決める | 判別が二か所以上に書かれるか、契約に現れる | 種類を明示の値（列挙型）として一か所で持ち、判別はその値で行う |
| 同じ知識を複数の場所に写す | 一つを変えると、他の写しも同時に直す必要がある | 知識を一か所に定義し、他の場所はそこから引くか生成する |
| 同じ概念を複数の語や綴りで書く | 境を越えて、その値を比べるか突き合わせる | 語を一つに決め、境を越える値は一つの型か定数で表す |
| 保存物の書く側と読む側の食い違い | 書く側が持つ列や名前の規則を、読む側が持たないか別の形で持つ | 書く側と読む側が同じ型か同じ定義を共有する |
| 同じ事実を引数と保存物の両方から受ける | 引数と保存物の値がずれたとき、どちらが正しいかを決める場所が無い | 事実の出所を一つに決め、もう一方からは受けない |
| いつも一緒に渡る値の群が型にならない | その群が契約に現れる | 群を一つの不変の型にして渡す |
| 境を越える型に内部の都合が漏れる（位置で並べた tuple、引数の名前空間をそのまま受けるなど） | その型を境の外が読む | 境に名前の付いた型を置き、内部の形はその内側に閉じる |
| 依存の向きが下位から上位へ向かう、または循環する | 下位の部品が上位の部品の形を知る | 共有する形を下位に置き、依存を上位から下位への一方向にする |
