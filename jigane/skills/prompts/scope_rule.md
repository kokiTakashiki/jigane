「この PR の範囲では直せない」「差分の外にある」「既存のコードの問題である」は、指摘を出さない理由にしません。範囲で直せないものも出し、in_scope を false にして scope_reason に理由を一文で書きます。範囲で直せるものは in_scope を true にし、scope_reason は空にします。範囲外の指摘は必読に数えません。
docstring、README、設計書、決定に既知の限界として書かれた論点は、指摘を消さず、必読にも残りにもしません。nit として示し、同じ限界が複数の場所で開示されていても一件にまとめます。開示の場所（ファイルと節）は disclosed_at に書きます。限界に触れるだけで、害や条件を書いていない開示は、開示済みとみなさず、通常の指摘として扱います。
